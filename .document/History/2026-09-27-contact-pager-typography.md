## 맥락

벤토 개편 뒤 사용자가 데스크톱·모바일을 실제로 보며 작은 지적을 이어서 냈다. 연락처가 모바일(동그라미)과 데스크톱(글자 목록)에서 모양이 달랐고, 상세 페이지를 모바일에서 넘길 방법이 없었다. 재직 배지와 AI 활용 제목은 색이 튀었고, 좁은 칸에서는 "정보기기운용기능 / 사"처럼 한 글자가 다음 줄로 떨어졌다.

## 결정

1. **연락처는 모든 폭에서 동그라미 넷(2×2).** 메일·전화는 누르면 복사, GitHub·LinkedIn은 링크다. 데스크톱 60px·아이콘 22px, 모바일 44px·18px이다. 푸터도 같은 동그라미 2×2(`.foot-ic`)를 쓰고, 글자 값(`.foot-right`)은 인쇄에서만 보인다.
2. **연락처 값은 마우스를 올리면 말풍선(`data-tip`)으로 보인다.** 호버 규칙 안에만 두어 터치에서는 뜨지 않는다. `title`은 브라우저 기본 풍선과 겹쳐서 뺐다.
3. **모바일 상세 페이저는 메뉴 안에 둔다(시안 A).** 상세에서 메뉴를 열면 켜진 "프로젝트" 줄 오른쪽에 번호(13px)와 ‹ › 동그라미(36px)가 붙는다. 데스크톱은 기존대로 "프로젝트" 칩 안의 페이저다.
4. **재직 배지 색은 `--badge` / `--badge-text` 토큰으로 바꿨다.** 라이트는 액센트 그대로, 다크는 태그와 같은 옅은 면이다. 다크에서 빨강·흰색이 모두 튀었기 때문이다.
5. **05 AI 활용 제목은 桜 → 藤 → 瑠璃 그라데이션(`--ai-1~3`)이다.** 사용자가 "AI가 떠오르는 색 + 일본색"으로 시안 ②를 골랐다.
6. **모바일 1칸 보조 프로젝트(자재관리 앱·MakeTApp)는 글자와 여백을 한 단계 줄였다.** 덜 중요한 카드라서다(기간 13 · 제목 16 · 요약 13 · 태그 11px).
7. **모바일 상세 히어로.** 표지 카드는 `min-height:338px`이다. 기간·결과물 보기 카드는 정사각형을 풀고 내용 높이로 두었다.
8. **프로젝트 카드 제목 옆 ↗를 모든 폭에서 지웠다.** 카드 전체가 누르는 면이다.
9. **데스크톱 상세 본문 내용(01 문단·02~05 항목)은 18px이다.** 섹션 제목(22px)과 모바일 값은 그대로다.

## 기각한 안

- **데스크톱 최소 글자 16 → 18 → 20px 일괄 상향**: 전부 되돌렸다. 배율 `.page{zoom:.9}` 때문에 CSS 18px은 화면에서 16.2px로 보인다. "18px 미만 0개"를 CSS 값으로만 잰 보고가 사용자 눈과 달랐다. 글자 크기 지시는 **화면에서 보이는 값**인지 먼저 확인한다.
- **상세 섹션 제목을 18px로**: 사용자는 제목 아래 내용을 뜻했고 모바일은 대상이 아니었다. 결정 9로 바로잡았다.
- **좁은 칸 줄바꿈 손질**: 한국어 자격증·기관명에 줄바꿈 자리(ZWSP)를 넣고 상세 성과 숫자를 한 줄로 묶었다가 되돌렸다. "정보처리 / 산업기사 · 한국산업 / 인력공단"처럼 쪼개진 모양이 더 어색하다는 사용자 판단이다.
- **일본어 `word-break:auto-phrase`**: 좁은 카드에서 구절이 통째로 넘어가 한 글자만 떨어지는 곳이 오히려 늘었다. 일본어는 `line-break:strict` 그대로 둔다.
