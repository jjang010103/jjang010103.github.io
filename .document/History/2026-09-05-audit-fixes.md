## ADR-001. 줄바꿈 규칙은 컴포넌트가 아니라 언어에 건다

**상태:** 채택 (적용 완료)

**맥락**
`word-break:keep-all`이 `.hero-lead` `.co-item` `.pc-blurb` `.m-item` 등 9개 컴포넌트 규칙에 직접 있었다. 한국어에는 어절 단위 줄바꿈이라 맞지만, 일본어는 어절 경계(공백)가 없어 같은 규칙이 "문장 전체를 한 덩어리로" 만든다. 실측: 375px 일본어에서 히어로 문장이 219px, 카드 blurb가 최대 208px 넘쳤고 문서 폭이 669px가 됐다. 모바일 브라우저는 넘친 만큼 레이아웃 뷰포트를 넓히므로(669×1449) `position:fixed` 바텀시트가 그 바닥에 붙어 화면에는 핸들만 보였다. body 스크롤은 잠겨 있어 상세를 볼 방법이 없었다.

**결정**
- `keep-all`은 `html[lang="ko"] body` 한 곳만. 컴포넌트에서는 전부 제거.
- `body{overflow-wrap:break-word}`를 안전망으로. 영어 긴 토큰(`Directory.Build.props`)도 여기서 잡힌다.
- `html[lang="ja"] body{line-break:strict}`.

**근거**
- 조판 규칙의 주체는 언어다. §5의 "언어 전환은 CSS 정적 표시"와 같은 축이다.
- `overflow-wrap:anywhere`가 아니라 `break-word`인 이유: `anywhere`는 min-content 크기에 개입해 그리드·플렉스 폭 계산을 바꾼다. `break-word`는 넘칠 때만 끊는다.

**결과**
- 세 언어 모두 375px 가로 오버플로 0. 모달 카드는 다시 뷰포트 안(top 65px).
- 모달 불릿에 2~5px `scrollWidth` 초과가 남는데, 줄 끝 강조 칩의 패딩(`.32em`)이 텍스트 박스 밖으로 걸리는 것이다. 본문 `padding-right:6px` 안에 있어 잘리지 않는다. 오버플로가 아니다.

## ADR-002. 모달은 dialog이고, 카드의 컨트롤은 제목 버튼 하나다

**상태:** 채택 (적용 완료)

**맥락**
`[data-modal]`에 `role`·`aria-modal`·`aria-labelledby`가 없었고 열어도 포커스가 페이지에 남았다. Tab을 누르면 시트 뒤의 로고 버튼으로 갔다. 카드는 `<article role="button" tabIndex="0">`이라 안의 `<h3>`가 버튼 이름에 묻혀 헤딩 탐색에서 프로젝트 제목 6개가 빠졌다.

**결정**
- `[data-modalcard]`에 `role="dialog" aria-modal="true" aria-labelledby="modal-title"`.
- `open()`: 열린 뒤 닫기 버튼으로 포커스, 모달의 형제 섹션에 `inert`. `closeModal()`: `inert` 해제, 카드 제목 버튼으로 포커스 복귀.
- 카드: `<article onClick>`은 클릭 면으로만 남기고 `h3 > button.pc-btn`이 유일한 컨트롤. 포커스 링은 `.proj-card:has(.pc-btn:focus-visible)`로 카드 테두리에 그린다.

**근거**
- 모달이 `main` 안에 있어 `main` 전체를 `inert`로 막을 수 없다. 형제만 잠그면 Tab이 모달 안에서 돈다. `inert`는 React가 모르는 속성이라 리렌더가 되돌리지 않는다.
- `.pc-text`는 `pointer-events:none`이라 버튼이 마우스 클릭을 가로채지 않고, Enter는 버튼의 click이 article로 버블링돼 같은 `open`을 탄다.

**결과**
- 키보드: 카드 제목 Tab → Enter → 닫기 버튼에 포커스 → Tab 순환이 시트 안 → Esc → 원래 카드 제목으로 복귀. 실측 확인.

## ADR-003. 보이지 않는 라벨도 `T` 상수에서 온다

**상태:** 채택 (적용 완료)

**맥락**
닫기 `aria-label="닫기"`(한국어 고정), 테마 `'Dark mode'`·복사 `'Copy email address'`(영어 고정). 언어 버튼 ㅎ/A/あ는 이름·상태가 없어 스크린리더가 자모 하나를 읽었다. "COPIED" 전환은 시각뿐이었다.

**결정**
`T.lang / toDark / toLight / pdf / close / copyEmail / copyPhone / copiedEmail / copiedPhone` 추가. 언어 세그먼트는 `role="group" aria-label` + 각 버튼 `aria-label`(자기 언어 표기) + `aria-pressed`. 복사 완료는 `.vh` 라이브 리전(`aria-live="polite"`)으로 알린다. 타임라인 공백은 `title`만 있던 것을 `.vh` 텍스트로도 넣었다.

**근거**
§5의 "세 언어 전부"를 접근성 계층까지 넓힌다. §8 검증 2번(`ko:|en:|ja:` 개수)이 이 상수들을 자동으로 센다.

## ADR-004. 토큰 대비 기준은 "놓이는 면"이다

**상태:** 채택 (적용 완료)

**맥락**
`--muted-2` 라이트 `#8a8983`는 배경 위 3.39:1, 카드 위 3.10:1이었고 히어로 연락처 행·모달 번호·서명 줄에 쓰였다. 다크 `#7d7d82`는 카드 위 4.15:1. `--line-ui` 테두리는 1.54:1 / 2.17:1. 모바일 로고의 "아직 안 읽은" 구간 색은 라이트 1.46:1이라 로드 직후 홈 버튼이 거의 보이지 않았다.

**결정**
| 토큰 | 이전 | 이후 | 기준 면 · 비율 |
| --- | --- | --- | --- |
| `--muted-2` light | `#8a8983` | `#6f6e68` | card 4.53 / bg 4.94 |
| `--muted-2` dark | `#7d7d82` | `#838388` | card 4.50 / bg 5.04 |
| `--line-ui` light | `#cfcdc6` | `#8d8b84` | card 3.02 / bg 3.29 |
| `--line-ui` dark | `#4a4a54` | `#72727c` | card-item 3.04 |
| 로고 rest light (JS) | `#d3d2cc` | `#93928c` | bg 3.01 |
| 로고 rest dark (JS) | `#4a4a53` | `#5f5f68` | bg 3.01 |

**근거**
글자는 4.5:1, 비텍스트 UI 경계는 3:1(WCAG 1.4.3 / 1.4.11). 값은 원래 색상에서 명도만 한 단계씩 옮겨 첫 통과 지점을 잡았다(색조 유지).

**결과**
`--line-ui`가 진해져 세그먼트·아이콘 버튼 테두리가 이전보다 또렷하다. 의도된 변화다.

## ADR-005. 작은 것들

**상태:** 채택 (적용 완료)

- **인쇄**: `@media print body{print-color-adjust:exact}`. 브라우저 기본 "배경 그래픽 끔"이 반전 블록의 배경만 버리면 `--ink-fg` 글자가 종이색이 된다. 이름·강조 칩·타임라인·푸터 연락처가 대상.
- **바텀시트 높이**: `92vh` 뒤에 `92dvh`를 덧썼다. 주소창이 펴진 상태에서 시트 바닥이 툴바 밑으로 들어가지 않는다.
- **손가락 타깃**: 모바일 블록에서 세그먼트 46px(안쪽 44), 아이콘 버튼 44×44, 로고 44px, 히어로 연락처·푸터 링크 `min-height:44px`.
- **721~800px 상단 바**: `.bar-nav`의 flex-basis 380 → 300. 760px에서 PDF 버튼이 둘째 줄로 내려가던 것이 한 줄(60px)로 돌아왔다.
- **스크롤 렌더**: `onScroll`이 `requestAnimationFrame`으로 합쳐 `measure()`를 호출. 스크롤·리사이즈·ResizeObserver가 한 프레임에 겹쳐도 setState 한 번.
- **`light-dark()` 폴백**: `@supports not (color:light-dark(red,blue))`에 라이트 팔레트 헥스. §8 검증 4번의 정규식(`#` 헥스 쌍)에 걸리지 않도록 조건식은 키워드 색을 썼다.
- **뷰 트랜지션**: `vt.ready.catch(()=>{})`. 탭이 백그라운드로 가면 DOM 갱신 콜백이 타임아웃으로 거부돼 콘솔에 unhandled rejection이 찍혔다.
- **삭제**: `PROJECTS[0].feature`, 세그먼트 색 객체의 `bc`. 참조 0.

## 기각

- **`.pc-img` 제거**: 감사에서 죽은 코드로 잡혔지만 [2026-09-03-main-redesign.md](./2026-09-03-main-redesign.md)에 이미지 파일을 넣으면 켜지는 경로로 기록돼 있다. 유지.
- **px → rem 전환**: 브라우저 글꼴 크기 설정을 따르게 하려면 시트 전체를 바꿔야 한다. 확대(zoom)는 정상 동작하므로 미룬다.

## 2부 — critique(UX 리뷰) 수정 (같은 날)

- 계기: `/impeccable critique` 25/36(Acceptable). P1 3건, P2 2건, Minor 8건
- 사용자 결정: 카드 빈 면은 **이미지로 채울 예정이라 유지**. MakeTApp의 75% 두 장은 **둘 다 사실**(첫 실행 로딩 / 페이지 이동 로딩). 나머지는 Minor까지 전부 수정.

### ADR-006. 연락처는 값을 보이고 연다

**맥락** 히어로의 `EMAIL` / `PHONE`은 클립보드 복사 버튼이었고 값은 푸터까지 내려가야 보였다. 모바일에서 `PHONE`을 눌러도 전화가 안 걸렸다. 푸터·모달 서명줄은 `mailto:`/`tel:`이라 세 곳이 세 방식이었다(H4·H6 감점).

**결정** 주소와 번호를 그대로 노출하고 `mailto:`/`tel:` 링크로. 복사는 옆의 28px(모바일 40px) 아이콘 버튼, 누르면 체크 아이콘으로 1.4초 바뀌고 `aria-live`가 읽는다. 모바일에서는 세 줄(이메일 / 전화 / 링크 둘)로 세운다.

**근거** 연락은 이 페이지의 유일한 전환 행동이다. 가장 지분 높은 행동이 가장 불투명하면 안 된다. 보이는 라벨과 접근 이름의 불일치(WCAG 2.5.3)도 함께 사라진다.

### ADR-007. 수치 카드는 `metrics` 문장이 먼저다

**맥락** MakeTApp `stats`에 `75%` 카드가 두 장인데 `metrics` 문장의 75%는 한 건뿐이라 §2 규칙 위반이자 복붙 실수로 보였다. 사용자 확인 결과 둘 다 사실: 웹뷰 **첫 실행** 로딩과 **페이지 이동** 로딩을 각각 75% 줄였다.

**결정** 새 수치를 만들지 않고 문장을 정확하게 고쳤다 — "웹뷰 첫 실행 로딩과 페이지 이동 로딩을 각각 75% 단축". 카드 라벨도 `첫 실행 로딩 단축` / `페이지 이동 로딩 단축`으로 구분. `.m-stats`는 고정 3열 → `repeat(auto-fit,minmax(160px,1fr))`(모바일 140px)이라 2장·3장 모두 빈 칸 없이 찬다. 한글·일본어 라벨은 본문 서체, 영어만 모노(`html[lang="en"] .m-stat-k`).

### ADR-008. 모달 안에서 넘긴다

**결정** 헤더 왼쪽에 `.m-pager`(‹ `n / 6` ›). 좌우 화살표 키 연결. 끝에서 멈추고 순환하지 않는다. 넘긴 뒤 본문은 맨 위로, 화살표가 disabled가 되어 포커스를 잃으면 닫기 버튼으로 옮긴다. 모바일 바텀시트는 상단 72px 또는 본문 맨 위에서 아래로 90px 스와이프하면 닫힌다 — 그려져 있던 드래그 핸들이 이제 거짓 어포던스가 아니다. 불투명 배경은 ADR-002(2026-09-03)를 존중해 유지.

### ADR-009. 모바일 내비를 되살린다

**맥락** `.bar-nav{display:none}`이라 5600px 페이지에 점프 수단이 없었다. 같은 블록이 핵심 스택의 반전을 지워 4군이 동급으로 보였다.

**결정** 내비를 상단 바 둘째 줄 스트립으로(`order:9; flex:1 1 100%`, 버튼 40px). 바가 60 → 102px이라 `scroll-margin-top` 124px. 핵심 스택(`.pill-on`)은 모바일에서도 반전 칩으로 남긴다.

### 작은 것들
- `NOW`만 영어로 남던 아이브로우: `date`는 `'2025.02 — NOW'` 한 형식 그대로 두고 렌더에서 `T.now`(현재 / NOW / 現在)로 치환.
- 반전 블록 안 muted 세 종류(.68/.62/.7 불투명도) → `--ink-fg-2` 토큰 하나(라이트 `#adadab` 8.2:1, 다크 `#545456` 5.4:1).
- 강조 칩 `margin:0 .04em` → `0`, 우측 패딩 .32em → .28em. "8년차가"의 조사 띄어짐 완화.
- 테마 토글 재클릭 가드(`_vtBusy`). PDF 버튼 아이콘을 프린터로(동작이 인쇄 대화상자다). 언어 버튼 `title`. 로고 `aria-label`(맨 위로). 스킵 링크(`.skip`, 포커스 시에만 보임). 연락처 버튼의 1px 포커스 링 삭제 → 전역 2px.

### 기각·보류
- **`.hero-sub`의 기술 용어**("C++ Native 연동부터 Java / Spring Boot 대용량 백엔드까지"): critique가 1차 독자(인사팀) 원칙 위반으로 짚었지만 사실 문구라 에이전트가 바꾸지 않는다. 사용자 판단 대기.
- **내비 `00 프로필` vs 본문 `01`부터**: 히어로는 챕터가 아니므로 번호가 없고, 내비의 00은 "챕터 이전"을 뜻한다. 일관성 문제로 보지 않아 유지.
- **일본어 모달 불릿 2~5px 초과**: 줄 끝 강조 칩의 패딩이 텍스트 박스 밖으로 걸리는 것. 카드 밖으로 새지 않아 유지.
- **얼굴·제품 화면 없음**: 사용자가 제공할 자산.

## 3부 — critique 재실행 수정 (같은 날, pill 내비·벤토 이후)

- 계기: `/impeccable critique index.html` 23/32(Good, 72%). 대상은 pill 내비·벤토 그리드가 들어간 미커밋 상태.
- 사용자 결정: 페이저는 고친다. `blurb`/`intro` 중복은 그대로 둔다. 스택 27개·학력 한 줄 등 **내용은 손대지 않는다**. 코드만.

### 고친 것
- **페이저 라벨**: 화살표 `aria-label`/`title`이 `다음 프로젝트: <제목>`. 번호(`n / 6`)만으로는 무엇을 넘기는지 몰랐다. 닫을 때 포커스는 **마지막으로 본 프로젝트의 카드**로 돌아간다(연 카드가 아니라).
- **시트 언어 세그먼트**: JS 인라인 헥스(`on.bg/fg`) 제거, 상단 pill과 같은 `is-on` 클래스로. 이로써 "JS가 색을 만드는 곳"이 0이 됐다 — DESIGN.md의 Chrome Exception 규칙은 폐기 대상.
- **모바일 스크롤바 복원**: 챕터 내비가 없는 모바일에서 유일한 위치 표시다. `html{scrollbar-width:none}` 삭제.
- **테마 전환 안전망**: `_vtBusy`를 800ms 타임아웃으로도 푼다. 백그라운드 탭에서 `finished`가 안 풀려 버튼이 죽던 경로.
- **접근성**: 카드 제목 버튼에 `aria-describedby`(요약 문단), 타임라인을 `<ol aria-label="근무 기간">`(`T.timeline` 3개 국어).
