# 벤토 개편 ("한 판의 벤토") + 프로젝트 상세 페이지

## 맥락
DESIGN.md를 디자인 시안 C(벤토 그리드) 기준으로 전면 개정했고, 이후 시안이 한 번 더 바뀌어(최종 시안 C + C-4) 사용자가 그 기준으로 사이트를 옮기라고 요청했다. 이전 "한 가지 잉크" 명세와 2026-09-24 결정(프로젝트 1열 목록, 스택 칩 금지)은 새 명세와 충돌한다.

## 결정
- 페이지를 쟁반(`--canvas`) 위 흰 카드 벤토로 다시 짰다. 4열 기본, 721~1000px 2열, 모바일 1열.
- 프로필 한 판: 액센트 히어로 3×2 · 총 경력(N년차, `CO[].period`에서 계산) · 연락처 잉크 카드(이메일·전화 복사, GitHub·LinkedIn) · 기술 스택 전체 폭(칩). 프로필 사진 칸과 구직 상태 카드는 시안에서 뺐다. 별도 스택 섹션이 없어져 내비 챕터가 5개에서 4개가 됐다.
- 경력은 회사별 카드(`auto-fit, minmax(360px, 1fr)`, 적으면 폭을 나눔). 근무 기간 타임라인 막대는 뺐다.
- 프로젝트 칸 수는 `PROJECTS[].span / rows`, 잉크 카드는 `ink`로 데이터가 정한다. 모양(대표·보조·가로형)은 칸 수에서 나온다.
- 학력·자격증·병역은 모두 "라벨 → 이름 → 보조 정보"의 같은 카드 형식. 아이콘 타일은 쓰지 않는다. 학력 데이터는 학교·전공·기간으로 나눴다.
- 푸터는 전체 폭 잉크 카드 하나(이름·연차·링크 / 이메일·전화 복사)와 그 아래 저작권·최종 수정 줄. CTA 문구는 없다.
- **프로젝트 모달을 없애고 `#/p/<id>` 해시 라우트 상세 페이지로 바꿨다.** 상세 뷰가 메인 콘텐츠를 대체한다.
- 서체는 Noto Sans KR/JP + Space Grotesk(데이터 전용). Pretendard·JetBrains Mono는 뺐다.
- 로고는 이름만. `.dev`와 액센트 점은 없다. 액센트는 메인 히어로·재직 배지·상세 히어로·상세 05 번호·포커스 링 다섯 곳.

## 근거
정보 한 종류당 카드 한 칸이라 인사담당자가 칸만 훑어도 요점을 읽는다. 상세를 페이지로 만들면 링크로 공유할 수 있고, 새로고침·뒤로가기가 자연스럽고, 모달의 포커스 트랩·`inert`·스와이프·바텀시트 코드가 통째로 사라진다. 타임라인 제거로 정적 인라인 스타일 예외 3개도 사라졌다.

## 결과
- 2026-09-24 프로젝트 1열 목록(`2026-09-24-project-list.md`)과 "기술 스택 칩 금지"를 대체한다.
- 제거한 모달 코드: `[data-modal]`/`[data-modalcard]` 오버레이·시트 스타일과 모바일 바텀시트, `setBackdropInert`(inert), 모달 Tab 포커스 트랩, `sheetStart/sheetEnd` 스와이프 닫기, `body` 스크롤 잠금, `stop` 전파 차단, 모달 서명 줄(`.m-foot`), 모달 그림자 토큰(`--shadow-1/2`), `T.close`.
- 총 경력은 근무 개월(양 끝 달 포함) 합 94개월 → 8년차로 계산된다. 히어로 문장의 "8년차"는 기존 문구 그대로다.
- 사진·프로젝트 이미지는 자리만 있다. `.impeccable/design.json`은 `/impeccable document`로 재생성했다.
