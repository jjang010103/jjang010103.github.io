# ADR — 반응형 배치와 메인 카드의 정보 범위

- 날짜: 2026-09-24
- 대상: `index.html`, `DESIGN.md`, `.impeccable/design.json`, `AGENTS.md`

## 맥락

800px 화면에서 2열 카드 안의 고정 이미지 폭 때문에 제목과 설명이 좁은 세로 열로 접혔다. 경력 기간 막대와 설명 열의 기준이 달랐고, 스택을 넓은 표로 바꾼 첫 수정은 사용자에게 기각됐다.

후속 요청은 스택 디자인 변경, 카드의 성과 전부 제거, PDF 버튼의 다운로드 아이콘 변경, 이메일·전화번호 하이퍼링크 제거다.

## 결정

- 721~1000px에서는 프로젝트를 한 행씩 배치한다. 이미지 폭은 지정값과 카드 폭 30% 중 작은 값이며, 빈 이미지는 단색 면으로 남긴다.
- 카드는 회사·기간·제목·기존 `intro` 개요만 표시한다. 카드의 수치 컴포넌트와 전용 바인딩을 삭제한다. 상세 모달의 `blurb`, `metrics`, `stats`는 보존한다.
- 경력은 기간 막대를 유지하면서 회사 정보와 업무를 한 행에 묶는다. 모바일은 회사별로 세로 배치한다.
- 스택의 표·행 구분선·반전 칩·모노 서체를 제거한다. 주력 기술은 24px 한 줄, 보조 기술은 제목 아래 본문 서체의 세 묶음이다. 모바일은 21px 주력 기술과 세로 묶음이다.
- 모바일 컨트롤은 상단 sticky 바에 두어 문서 흐름에 공간을 확보한다. 챕터 내비는 계속 숨긴다.
- PDF 버튼은 16px 다운로드 SVG로 바꾼다. `window.print()`와 3개 언어 라벨은 유지한다.
- 이메일·전화번호는 히어로·푸터·모달 모두 일반 텍스트로 표시한다. 기존 복사 버튼만 동작한다. GitHub·LinkedIn 링크는 유지한다.
- 긴 모바일 섹션 제목의 줄바꿈, 320px 푸터 최소폭, 모달 하단 페이드, 모달 Tab/Shift+Tab 순환을 보정한다.
- 인쇄 본문의 `color-scheme:light`를 지정한다. HTML의 저장된 다크 설정이 인쇄 글자를 밝게 만드는 문제를 실제 인쇄 CSS 화면에서 확인했다.

## 근거

성과를 카드에서 먼저 보여주는 구성과 연락처 하이퍼링크는 이번 사용자 지시로 변경한다. 2026-09-05의 해당 결정은 이 범위에서 대체된다. 스택을 고정 열로 화면 끝까지 벌리는 방식은 기각됐으므로 다시 도입하지 않는다.

## 결과 및 검증

- 한국어·영어·일본어 × 실제 뷰포트 1280/1002/800/720/375/320px: 가로 넘침 0px.
- 모바일 3개 언어 화면, 라이트/다크 화면, 카드와 상세 모달 렌더 확인.
- 카드 성과 컴포넌트 0개, 이메일·전화 링크 0개. 모달 ezZip 수치 카드 3개 유지.
- 이메일·전화 복사 값 확인. Enter로 모달 열기, Tab/Shift+Tab 양방향 순환, Esc 후 카드 포커스 복귀 확인.
- 언어 짝: 템플릿 인라인 21/21/21, 블록 13/13/13, 스크립트 118/118/118. `!important` 0, 모바일 블록 1, 금지 셀렉터 0.
- 인쇄 CSS의 카드 단일열·이미지와 도구막대 숨김·밝은 종이색과 어두운 글자 확인. 이 환경의 내장 브라우저는 인쇄 대화상자를 표시하지 않고 PDF 생성도 `Printing is not available`로 거절하므로, 실제 페이지 나눔과 PDF 파일 출력은 미검증이다.
- 레이아웃 detector의 잔여 경고 2개는 도구막대/이미지 래퍼의 내부 여백이다. 버튼의 자체 크기(모바일 44px)와 캡션의 8px 여백을 렌더에서 확인했다.
- `support.js`, 프로젝트 사실·수치 데이터는 변경하지 않았다. 커밋·배포하지 않았다.
